How to Create a New Blog Post

The clean workflow is to keep the homepage static and drop new article content into the Markdown post collection.

For a new entry, create a file in the posts directory with a date-prefixed filename and add the title, description, date, and tags in front matter.

After that, write the body in Markdown and push the change. GitHub Pages will render the new page automatically.
